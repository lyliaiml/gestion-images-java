
# Application de gestion d'images

## Présentation

Projet universitaire réalisé en mars 2026 dans le cadre de mon parcours informatique.

L'objectif est de développer une application Java permettant de charger, afficher et manipuler des images à travers une interface graphique.

## Fonctionnalités

- Chargement d'images
- Affichage des images
- Manipulation et traitement des images
- Interface graphique interactive

## Technologies utilisées

- Java
- Programmation orientée objet
- Interface graphique

## Organisation du projet

- `src/` : code source de l'application
- `docs/` : sujet et rapport du projet
